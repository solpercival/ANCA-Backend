# Appendix A2: TCG Constants

This appendix documents EPPL constants specific to Tool and Cutter Grinder (TCG) applications. These are only available on machines configured for tool grinding. For TCG functions, see Appendix A1.

## Integer Constants

### `tg_bk_surf`

Back surface selection flag.

**Value:** `0`

### `tg_c1`

Grind using right side of wheel.

**Value:** `0x10`

### `tg_def_c`

Define `C` in input to transform.

**Value:** `0x01`

### `tg_def_cl`

Define clearance in input to transform.

**Value:** `0x00`

### `tg_e0`

Edge type: straight-straight.

**Value:** `0x01`

### `tg_e1`

Edge type: straight-curve.

**Value:** `0x02`

### `tg_e2`

Edge type: curve-straight.

**Value:** `0x04`

### `tg_e10`

Edge type flag.

**Value:** `0x20`

### `tg_e11`

Edge type flag.

**Value:** `0x40`

### `tg_e12`

Edge type flag.

**Value:** `0x80`

### `tg_eff`

Use effector offsets.

**Value:** `0x8000`

### `tg_ft_surf`

Front surface selection flag.

**Value:** `0x08`

### `tg_left_cut`

Left cut surface selection.

**Value:** `0x04`

### `tg_left_hx`

Left hex surface selection.

**Value:** `0x02`

### `tg_no_flags`

No flags set.

**Value:** `0x00`

### `tg_non_std_c`

Non-standard `C` setting.

**Value:** `0x10`

### `tg_ok`

Success return value.

**Value:** `0x00`

### `tg_r1`

Specify rotation angle.

**Value:** `0x08`

### `tg_right_cut`

Right cut surface selection.

**Value:** `0x00`

### `tg_right_hx`

Right hex surface selection.

**Value:** `0x00`

### `tg_set_a`

Set `A` axis return value flag.

**Value:** `0x01`

### `tg_std_c`

Standard `C` setting.

**Value:** `0x00`

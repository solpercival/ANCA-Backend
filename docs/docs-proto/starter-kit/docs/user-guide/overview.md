# AMCore User Guide

This guide introduces you to ANCA Motion's AMCore software. It provides instructions for getting started, configuring and using AMCore.

In this user guide, the following instructional icons are used:

> [!NOTE]
> Useful information to be aware of, even when skimming.

> [!TIP]
> Optional, related information that could be helpful.

> [!IMPORTANT]
> Essential information needed to avoid mistakes.

> [!CAUTION]
> Potential consequences of an action.

> [!WARNING]
> Serious consequences of an action.

The information contained in this guide was correct at the time of writing, but is subject to change. Please ensure you always refer to the version of the guide corresponding to the AMCore version you are using.

## Terms and abbreviations

| Term        | Definition                                                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------- |
| API         | Application Programming Interface                                                                                             |
| Bundle      | A collection of installation packages that are chained together into a single user experience                                 |
| CNC         | Computer Numerical Control                                                                                                    |
| EPPL        | [Extended Part Programming Language](./concepts.md#extended-part-programming-language-eppl)                                   |
| Feedrate    | The rate of movement of the end effector through the work-piece                                                               |
| Home folder | The folder where OEMs keep their files. More information: [Home folder](./get-started/set-up-your-environment.md#home-folder) |
| INtime      | Real-time operating system that runs alongside Microsoft Windows on ANCA Motion CNCs                                          |
| IO          | Input/Output                                                                                                                  |
| LM          | [Logical Machine](./concepts.md#logical-machine)                                                                              |
| MPG         | [Manual Pulse Generator](./concepts.md#manual-pulse-generator-mpg)                                                            |
| MUP         | Machine Update Period                                                                                                         |
| OEM         | Original Equipment Manufacturer                                                                                               |
| OS          | Operating System                                                                                                              |
| PLC         | [Programmable Logic Controller](./concepts.md#programmable-logic-controller-plc)                                              |
| PLCL        | PLC Language                                                                                                                  |
| RAM         | Random Access Memory                                                                                                          |
